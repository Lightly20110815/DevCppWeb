Dev-C++ 网页版：浏览器里的 C++ IDE 与在线编译器

Dev-C++ Web 用 React、CodeMirror 和 Clang/WebAssembly 重建了 Dev-C++ 5.11 的桌面界面。打开网页即可新建 C++ 源文件，按 F11 保存、编译并运行，不需要安装任何软件。支持 C++17/20、语法高亮、自动补全、项目管理、搜索替换和虚拟文件系统。编译器完全在浏览器本地运行，代码不会上传到服务器。

主要功能

  • 在线编译 C++ 并直接运行，支持控制台键盘输入
  • Clang/WebAssembly 工具链，本地编译，保护代码隐私
  • 经典 Dev-C++ 5.11 界面、图标、菜单和快捷键
  • CodeMirror 编辑器的语法高亮、自动补全与搜索替换
  • 项目、多文件编译、增量构建和结果缓存
  • 浏览器内虚拟文件系统，刷新后文件仍然保留

使用方式

用桌面版 Chrome 或 Edge 打开本站，首次加载会下载约 100 MiB 的编译器资源；之后可以新建源文件、打开示例项目，或从电脑导入文件夹。编译输出为 WebAssembly 格式，并非 Windows 原生程序。

在线地址：https://devcppweb.vercel.app/
